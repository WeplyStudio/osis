# **App Name**: OASISverse

## Core Features:

- Event Listings: A continuously updated listing of the organization's events, along with descriptions, dates, times and locations.
- Photo Gallery: Display photos from the OSIS organization events.
- Announcements: Important announcements relevant to the students, which may come in the form of a scheduled push notification.
- AI-Powered Idea Tool: Students can suggest new initiatives for the organization. An AI tool analyzes suggestions for feasibility and popularity to help the organization make informed decisions about which proposals to consider. Includes AI-suggested tags to help categorize. This feature includes an AI tool.

## Style Guidelines:

- Primary color: Bright blue (#4285F4) inspired by Stumble Guys and the provided reference, creating a playful, energetic atmosphere.
- Background color: Light gray (#F5F5F5), a soft backdrop to make the vibrant colors stand out, allowing users to easily see information.
- Accent color: Yellow (#FFEB3B), drawing attention to CTAs, similar to the yellow highlights in the reference UI.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, and 'Inter' (sans-serif) for body text.
- Use playful icons and illustrations inspired by the color palette and Stumble Guys's cartoony, energetic visual style.
- Layout elements should include rounded corners and consider generous use of white space to avoid the appearance of clutter. Try to maintain visual similarity to [the requested website] and the reference where practical, including a large hero section and card-based content display.
- Animations when transitioning between pages, revealing information, or submitting an idea. Make the app feel more fun and energetic.
